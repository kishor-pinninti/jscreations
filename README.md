# JS Creations

*Just Style Your Simplicity*

Website for JS Creations, handcrafted temple-style artificial jewellery by Prasanna, Vizianagaram.

Live site: https://kishor-pinninti.github.io/jscreations/

## Changing the site colours (owner)

1. Open https://kishor-pinninti.github.io/jscreations/#owner
2. Tap a colour theme to preview it.
3. Tap **Save for everyone**. Visitors see the new colours about a minute later.

The first save asks for a save key (a GitHub fine-grained token with *Contents: Read and write* on this repository only). It is stored only on that device.

## Editing pieces and prices

Everything is in `index.html`, in the `CATEGORIES` and `PIECES` lists near the bottom. Set a piece's `price` to a number in rupees, e.g. `price: 1450`. Photos live in `images/`.
